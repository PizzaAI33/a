# Foundry Arsenal 0.7.0 downloads

Download `Foundry_Arsenal_0.7.0.mcaddon`, then open it with Minecraft Bedrock. If your browser blocks the extension, download `Foundry_Arsenal_0.7.0_Download.zip` and extract the add-on first.

Activate both matching version 0.7.0 packs in a new test world. Requires Bedrock 1.21.120 or newer. The Field Manual provides the controls and the new Field Journal.

`Foundry_Arsenal_Source.zip` contains the complete editable project, generated packs, tests and validation report. `Foundry_Arsenal_Field_Guide.html` is an offline guide. File checksums are in `SHA256SUMS.txt`.

Verified: 62 gameplay tests, 5,579 asset/structure checks, and stable Bedrock API type compatibility. Actual Minecraft client play-testing remains pending.

This branch contains downloads only; project source changes remain in the working repository and in the source archive.
